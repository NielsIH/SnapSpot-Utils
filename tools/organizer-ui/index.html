How to use
  1. Configure default paths on the Configuration page
  2. Select export, search, and output paths
  3. Choose organization options and copy the generated command
  4. Open PowerShell/Terminal in the cli directory
  5. Paste and run the command
⚠️ Organizer shows compact photo-search summary only. For detailed missing-photo diagnostics, run Photo Finder with --report --log.
💡 Reuse mode: first generate a manifest with Photo Finder using --manifest, then use that JSON file as Organizer input.
